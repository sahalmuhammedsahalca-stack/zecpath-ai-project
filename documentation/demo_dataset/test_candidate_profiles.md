# Day 63 – Test Candidate Profiles

## Candidate 001

### Scenario

Strong candidate for the Data Analyst position.

### Profile

- Experience: 2 years
- Profile quality: High
- Strong SQL and Python skills
- Power BI experience
- Strong interview performance

### Expected Result

**Highly Recommended**

---

## Candidate 002

### Scenario

Borderline/entry-level candidate.

### Profile

- Experience: 6 months
- Profile quality: Medium
- Basic SQL and Python skills
- Basic Power BI experience
- Limited professional experience

### Expected Result

**Recommended**

---

## Candidate 003

### Scenario

Candidate with poor technical fit for the Data Analyst position.

### Profile

- Experience: 2 years
- Profile quality: Low
- Mainly administrative experience
- Limited analytical skills
- Limited technical interview performance

### Expected Result

**Needs Review**

---

## Purpose

These three profiles represent different real-world hiring scenarios:

1. Strong candidate
2. Borderline candidate
3. Poor technical fit

This allows the Zecpath AI system to demonstrate different evaluation outcomes.
