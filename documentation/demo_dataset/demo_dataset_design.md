# Day 63 – Demo Dataset Design

## Objective

Prepare realistic sample data to demonstrate the complete Zecpath AI hiring pipeline.

## Dataset Components

The demo dataset contains:

- Sample resumes
- Job descriptions
- Candidate interview responses
- Simulated ATS results
- Simulated screening results
- Simulated interview results
- Candidate profiles
- Complete hiring pipeline data

## Candidate Scenarios

### CAND001 – Strong Candidate

A candidate with strong technical and analytical skills, relevant experience, and strong interview performance.

Expected outcome:

**Highly Recommended**

### CAND002 – Borderline Candidate

A candidate with basic relevant skills and limited professional experience.

Expected outcome:

**Recommended**

### CAND003 – Poor Technical Fit

A candidate with limited technical and analytical experience for the Data Analyst position.

Expected outcome:

**Needs Review**

## Purpose

The different candidate profiles allow the system to demonstrate different hiring outcomes instead of testing only ideal candidates.
