# HR Interview AI – API Specification

## 1. Overview

This document describes the API integration structure for the HR Interview AI system.

The API layer allows external applications to communicate with the AI recruitment modules.

## 2. API Purpose

The API is designed to support:

- Candidate data submission
- Resume processing
- Job description processing
- Candidate evaluation
- Screening evaluation
- HR interview evaluation
- Unified scoring
- Candidate ranking
