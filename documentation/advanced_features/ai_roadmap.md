# AI Roadmap

## Phase 1 — Short Term

Focus on structured intelligence.

Features:

- Interview analytics
- Candidate improvement suggestions
- AI coaching prototype
- Better reporting

## Phase 2 — Medium Term

Introduce advanced interview intelligence.

Features:

- Real-time feedback
- Speech analysis
- Video interview analysis
- Advanced interview metrics

## Phase 3 — Long Term

Build scalable multimodal AI.

Features:

- Multimodal AI models
- Scalable model infrastructure
- Enterprise analytics
- Continuous model evaluation
- Advanced AI-assisted recruitment

## Scaling Principles

The system should use modular services so new AI capabilities can be added
without replacing the existing recruitment pipeline.

Model outputs should be validated before entering the hiring decision layer.

Human review should remain available for important decisions.
