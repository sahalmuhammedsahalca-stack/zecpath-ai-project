\# Export-Ready Hiring Report Format



\## 1. Purpose



The Export-Ready Hiring Report Format defines the structure used to present the final candidate evaluation report.



\## 2. Candidate Information



The report should include:



\- Candidate ID

\- Candidate Name

\- Job Role



\## 3. Overall Evaluation



The report should include:



\- Overall score

\- Hiring fit percentage

\- Confidence score



\## 4. Evaluation Summary



The report should summarize:



\- ATS performance

\- Screening performance

\- HR interview performance

\- Technical performance

\- Behavioral performance



\## 5. Strengths



The candidate's strongest evaluation areas should be listed clearly.



\## 6. Weaknesses



Areas requiring improvement should be listed clearly.



\## 7. Risk Indicators



Relevant risk indicators should be displayed separately.



\## 8. Final Recommendation



The report should clearly display:



\- Recommendation

\- Confidence score

\- Decision explanation



\## 9. Recruiter Summary



A short recruiter-friendly summary should provide the main hiring insights.



\## 10. Export Structure



The report should be structured so that it can be displayed or exported in a consistent format.



\## 11. Expected Outcome



The Export-Ready Report Format provides a clear and professional structure for presenting AI-generated candidate evaluation results to recruiters.
