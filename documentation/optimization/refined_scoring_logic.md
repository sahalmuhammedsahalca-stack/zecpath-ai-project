# Refined Scoring Logic

## 1. Purpose

The refined scoring logic improves candidate classification by using clearer score thresholds.

## 2. Score Categories

The optimized scoring model uses:

- 85–100: Highly Recommended
- 70–84: Recommended
- 60–69: Needs Review
- Below 60: Not Recommended

## 3. Optimization Goal

The purpose of the refined thresholds is to reduce ambiguous classification and improve consistency in candidate evaluation.

## 4. Explainability

Each classification should retain the candidate score and the classification assigned by the scoring model.

## 5. Expected Outcome

The refined scoring logic provides clearer separation between candidate performance levels.
