# Cross-Round Optimization

## 1. Purpose

Cross-round optimization evaluates whether candidate scores remain consistent across multiple interview rounds.

## 2. Consistency Measurement

The system calculates:

- Average score
- Score variation
- Consistency classification

## 3. Classification

Score variation is classified as:

- 0–10: High consistency
- 11–20: Moderate consistency
- Above 20: Low consistency

## 4. Expected Outcome

The analysis helps identify unusual changes in candidate performance across different evaluation rounds.
