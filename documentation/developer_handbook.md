# HR Interview AI – Developer Handbook

## 1. Purpose

This handbook provides basic instructions for developers working with the HR Interview AI project.

It explains the project structure, development workflow, testing process, integration approach, and troubleshooting steps.

## 2. Project Structure

The main project contains separate modules for different AI responsibilities.

Important modules include:

- parsers
- ats_engine
- screening_ai
- screening_scoring
- communication_analysis
- communication_evaluation
- communication_scoring
- confidence_analysis
- aptitude_logic
- interview_question_engine
- conversation_flow
- dynamic_followup
- hr_interview_engine
- hr_interview_simulation
- interview_summary
- unified_scoring
- candidate_ranking
- optimization
- system_testing
- tests
