# Decision Audit Logging

## Day 61

The decision audit system records important information about AI hiring decisions.

## Recorded Information

Each decision can contain:

- Timestamp
- Candidate ID
- Score
- Recommendation
- Reason

## Purpose

Audit records make AI decisions easier to review and trace.

## Candidate Lookup

The system can retrieve audit records for a specific candidate.

## Benefit

Decision auditing provides a structured record that can support debugging, review, and governance of AI-generated recommendations.
