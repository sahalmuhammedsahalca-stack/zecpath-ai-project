# Logging Structure

## Day 61

The logging system records important AI system events.

## API Logs

API logs contain:

- Timestamp
- Endpoint
- HTTP method
- Status
- Response time

## Model Output Logs

Model logs contain:

- Timestamp
- Model name
- Model output
- Score when available

## Error Logs

Error logs contain:

- Timestamp
- Error type
- Error message

## Purpose

These logs help developers understand system activity, identify errors, and debug AI processing problems.
