# Metrics and Alerting

## Day 61

The monitoring system tracks important AI performance metrics.

## Key Metrics

### Response Time

Measures how long an AI/API operation takes.

### Accuracy

Measures the percentage of correct AI evaluation results.

### Failure Rate

Measures the percentage of failed requests.

## Alert Rules

The system can generate alerts when:

- Response time is too high
- Accuracy falls below the required level
- Failure rate becomes too high

## Default Prototype Thresholds

- Maximum response time: 1 second
- Minimum accuracy: 80%
- Maximum failure rate: 10%

## Purpose

Alerting allows problems to be detected quickly before they affect a large number of candidates.
