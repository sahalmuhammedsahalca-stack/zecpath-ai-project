# Zecpath AI – Developer Onboarding Guide

## 1. Purpose

This guide helps new developers understand the Zecpath AI project and start development safely.

## 2. Project Structure

Important project areas include:

- `parsers` – Resume and job-description parsing
- `ats_engine` – ATS evaluation
- `hr_screening` – Candidate screening
- `hr_interview_engine` – HR interview processing
- `technical_interview` – Technical interview processing
- `behavioral_analysis` – Behavioral evaluation
- `integrity_detection` – Integrity evaluation
- `unified_scoring` – Cross-round scoring
- `final_recommendation` – Final hiring recommendation
- `hiring_intelligence_report` – Candidate reports
- `security_governance` – Security and governance
- `api_integration` – API integration
- `performance_scaling` – Performance and scalability
- `monitoring_observability` – AI monitoring
- `tests` – Automated tests
- `documentation` – Technical documentation
