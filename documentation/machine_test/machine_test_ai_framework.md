\# Machine Test AI Framework



\## 1. Purpose



The Machine Test AI evaluates a candidate's real-world technical skills through practical tasks.



The system provides structured tasks based on the candidate's role, required skills, and difficulty level.



\## 2. Machine Test Types



The system supports:



\- Coding problems

\- Debugging tasks

\- File-based tasks

\- Mini system design



\## 3. Task Creation



Each machine test contains:



\- Job role

\- Task type

\- Difficulty

\- Required skills

\- Time limit



\## 4. Task Flow



Task Creation

↓

Task Assignment

↓

Candidate Execution

↓

Output Capture

↓

Task Evaluation

↓

Time Evaluation

↓

Final Scoring

↓

Performance Classification



\## 5. Role-Based Testing



Tasks should be selected according to the candidate's job role and required technical skills.



For example:



Python Developer:



\- Python

\- Problem solving

\- Debugging



\## 6. Difficulty



Machine tests may be classified as:



\- Basic

\- Intermediate

\- Advanced



The difficulty should reflect the candidate's experience and job requirements.



\## 7. Input and Output Capture



The system should capture:



\- Candidate code snapshots

\- Execution results

\- Task completion information

\- Time taken



\## 8. Evaluation



The system evaluates:



\- Correctness

\- Efficiency

\- Code quality

\- Problem-solving approach

\- Time performance



\## 9. Expected Outcome



The Machine Test AI provides a structured method for evaluating practical technical skills through real-world tasks.
