# Zecpath AI – Internship Portfolio

## Project Overview

Zecpath AI is an AI-assisted recruitment platform designed to improve the efficiency and consistency of candidate evaluation.

The project focuses on applying AI and software engineering techniques across multiple stages of the recruitment process.
