# Technical Interview AI – Question Hierarchy Model

## 1. Purpose

The Question Hierarchy Model defines how technical interview questions are organized according to difficulty, candidate experience, and interview progression.

## 2. Question Levels

### Level 1 – Basic

Focus:

- Fundamental concepts
- Basic terminology
- Simple technical questions
- Core programming knowledge

Purpose:

To verify whether the candidate understands the basic concepts required for the role.

### Level 2 – Intermediate

Focus:

- Practical implementation
- Technical concepts
- Common development problems
- Application of knowledge

Purpose:

To evaluate whether the candidate can apply technical knowledge in practical situations.

### Level 3 – Advanced

Focus:

- Complex technical concepts
- Advanced implementation
- Optimization
- Architecture-related decisions

Purpose:

To evaluate deeper technical knowledge and professional-level understanding.

### Level 4 – Scenario-Based

Focus:

- Real-world technical situations
- Problem solving
- Debugging
- Decision making
- Trade-offs

Purpose:

To evaluate how the candidate handles practical technical problems.

### Level 5 – System Design

Focus:

- System architecture
- Scalability
- Reliability
- Component design
- Technical decision making

Purpose:

To evaluate the candidate's ability to design and reason about larger technical systems.

## 3. Experience Mapping

| Candidate Experience | Starting Level |
|---|---|
| 0–2 years | Basic |
| 3–5 years | Intermediate |
| 5+ years | Advanced |

The system may adjust the level based on the candidate's demonstrated performance.

## 4. Progression Rules

Strong performance:

Basic
↓
Intermediate
↓
Advanced
↓
Scenario-Based
↓
System Design

Weak performance:

Advanced
↓
Intermediate
↓
Basic

The system should avoid increasing difficulty too quickly when the candidate is consistently struggling.

## 5. Question Categories

Technical questions can be categorized into:

- Conceptual
- Coding
- Practical
- Debugging
- Scenario-Based
- Architecture
- System Design

## 6. Adaptive Question Selection

The next question is selected using:

- Candidate experience
- Job role
- Required skills
- Current difficulty
- Previous answer quality
- Previous question category
- Interview performance

## 7. Skill Coverage

The interview should ensure that questions cover the important technical skills required for the candidate's job role.

Example:

For a Java Developer:

- Core Java
- OOP
- Spring
- Spring Boot
- REST APIs
- Database concepts

For a DevOps Engineer:

- Linux
- Git
- Docker
- CI/CD
- Kubernetes
- Cloud fundamentals
- Monitoring

## 8. Question Repetition Control

The system should avoid repeatedly asking the same question.

If a candidate has already demonstrated sufficient understanding of a topic, the system should move toward another relevant skill or a higher difficulty level.

## 9. Knowledge Gap Detection

Repeated weak answers in a particular skill area may indicate a knowledge gap.

The system can respond by:

- Asking a simpler supporting question
- Testing the same concept differently
- Recording the skill as a weak area
- Continuing with another relevant topic

## 10. Final Question Distribution

A technical interview should contain a balanced combination of:

- Basic questions
- Intermediate questions
- Advanced questions
- Practical questions
- Scenario-based questions

The exact distribution may depend on candidate experience and job requirements.

## 11. Expected Outcome

The Question Hierarchy Model provides a structured method for selecting technical questions while allowing the interview to adapt to candidate experience, performance, and technical skill level.
