# Data Analyst – Demo Job Description

## Position

Data Analyst

## Experience

1–3 years

## Required Skills

- SQL
- Python
- Pandas
- Excel
- Power BI
- Data Cleaning
- Data Visualization
- Basic Statistics

## Responsibilities

- Clean and analyze business data.
- Prepare reports and dashboards.
- Identify trends and patterns.
- Write SQL queries.
- Support business decision-making.
- Communicate analytical findings.

## Preferred Skills

- DAX
- Power Query
- Tableau
- Business analysis experience

## Education

Bachelor's degree in a relevant discipline.

## Hiring Priority

Candidates with strong analytical thinking, communication skills, and practical data-analysis experience are preferred.
