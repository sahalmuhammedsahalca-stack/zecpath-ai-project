# Coding Standards

## Naming Rules

- File names should use lowercase letters.
- Variable names should use snake_case.
- Function names should use snake_case.
- Class names should use PascalCase.

## Comments

- Write comments only when necessary.
- Keep code simple and readable.

## Logging

- Use the Python logging module instead of print() for application logs.

## Folder Structure

- Keep related files inside their respective folders.
- Do not mix unrelated files.

## Documentation

- Every Python file should have a short description at the top explaining its purpose.
